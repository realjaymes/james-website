## Why this exists

This site used to be a Notion page, redirected through a Cloudflare Worker. That was the right call back when I didn't have a dev workflow. Once I started running Claude Code every day, Notion's design ceiling became the actual constraint, especially next to other operators in my own market who all run hand-coded sites of their own. I rebuilt it the same way I rebuilt Marketing In Action's site: research competitors first, then build in code.

Read the full story on the [James Website](https://jamespraise.xyz/work/james-website/) case study on this site.

## Tech Stack

- HTML, CSS, and vanilla JavaScript, no framework
- Built with [Claude Code](https://docs.anthropic.com/en/docs/claude-code), the same way I build Marketing In Action's site
