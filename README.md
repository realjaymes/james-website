# James Praise

My personal site: jamespraise.xyz

I'm [James](https://www.jamespraise.xyz), a product marketing and go-to-market operator, and founder of [Marketing In Action](https://marketinginaction.xyz). This is my portfolio: 11 real client case studies, a set of side projects I've built for myself, and the writing and speaking I do outside client work.

I am currently experimenting with vibe coding, and this is one of the projects I'm building with that knowledge. You can also check out the vibe-coded repo of the MIA website here: [github.com/realjaymes/marketinginaction](https://github.com/realjaymes/marketinginaction).

## Why this exists

This site used to be a Notion page, redirected through a Cloudflare Worker. That was the right call back when I didn't have a dev workflow. Once I started running Claude Code every day, Notion's design ceiling became the actual constraint, especially next to other operators in my own market who all run real, coded sites. I rebuilt it the same way I rebuilt Marketing In Action's site: research real competitors first, then build in code.

Read the full story on the [James Website](https://jamespraise.xyz/work/james-website/) case study on this site.

## Tech Stack

- HTML, CSS, and vanilla JavaScript, no framework
- Built with [Claude Code](https://docs.anthropic.com/en/docs/claude-code), the same way I build Marketing In Action's site
